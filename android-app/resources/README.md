# Recursos de marca Android

Coloca aquí los recursos finales antes de generar el proyecto nativo.

## Archivos recomendados

```txt
icon-1024.png
splash-2732x2732.png
foreground-icon.png
background-color.txt
```

## Paleta inicial

```txt
Azul PIAGET oscuro: #07142f
Verde acento: #42e8b4
Azul acento: #4f7cff
```

## Icono recomendado

- Formato: PNG.
- Tamaño: 1024 x 1024 px.
- Fondo sólido o degradado azul oscuro.
- Isotipo PIAGET centrado.
- Mantener margen seguro de 18%.

## Splash recomendado

- Formato: PNG.
- Tamaño: 2732 x 2732 px.
- Fondo azul oscuro.
- Isotipo PIAGET centrado.
- Sin texto pequeño para evitar recortes.
